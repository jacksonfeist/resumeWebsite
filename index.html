Jira app / Atlassian Forge

Secure Fields for Jira

Healthcare, legal, and finance teams keep sensitive values in Jira fields that were never built to protect them. Secure Fields keeps those values out of Jira's data layer entirely: they live in Forge storage on Atlassian's platform and render only for the groups and project roles you allow. Everywhere else (REST, JQL, CSV export) sees a marker token instead of the value, and every read and write is checked server-side, deny by default.

I designed and built it solo: the app, the threat model, the write-vector test suites, and the Marketplace listing.

  • TypeScript
  • React
  • Atlassian Forge
  • Jira
  • Security
