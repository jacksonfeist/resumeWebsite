Selected work

Atlassian Forge · Product build

Secure Fields for Jira

A field-level security app for regulated Jira teams — healthcare, finance, legal. Values entered through Secure Fields never sit in Jira's data layer: they live in Forge storage on Atlassian's platform and render only for authorized groups and project roles. REST, JQL, and CSV export see only a marker token, and every read and write is checked server-side, deny by default.

Designed, built, and verified solo — from threat-model docs and write-vector test suites to Marketplace listing prep.
